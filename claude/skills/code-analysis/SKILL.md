# Code Analysis Format

When analyzing code, structure your response with these sections:

1. **Code Analysis** — what the existing code does, how it's structured
2. **Code Smell Analysis** — identify potential smells and propose solutions
3. **Suggested Improvements** — specific, actionable changes ranked by priority
4. **Code Examples** — show before/after for key improvements
5. **Testing Strategy** — how to test the changes, what coverage looks like
6. **Implementation Guidelines** — ordering, risks, dependencies
